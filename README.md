## プロジェクト概要

このプロジェクトは、SwiftUIを使用したiOSアプリケーションです。Swift Package Manager形式で構成されており、XcodeとSwift Playgroundsの両方で開くことができます。

## 必要環境

- Xcode 15.0以上
- iOS 17.0以上
- Swift 6.0

## Xcodeで開く方法

このプロジェクトをXcodeで開くには、以下のいずれかの方法を使用してください：

### 方法1: Finderから開く

1. Finderでプロジェクトフォルダを開く
2. `.swiftpm/xcode/package.xcworkspace` ファイルをダブルクリック

### 方法2: ターミナルから開く

```bash
open .swiftpm/xcode/package.xcworkspace
```

### 方法3: Xcodeから開く

1. Xcodeを起動
2. **File** > **Open...** を選択
3. プロジェクトフォルダ内の `.swiftpm/xcode/package.xcworkspace` を選択

## アプリの実行方法

1. Xcodeでプロジェクトを開く
2. シミュレータまたは実機を選択
3. **⌘R** を押すか、**Product** > **Run** を選択してアプリを実行

## プロジェクト構成

- `MyApp.swift` - アプリのエントリーポイント
- `ContentView.swift` - メインのSwiftUIビュー
- `Package.swift` - Swift Package Manager設定ファイル

## Swift Playgroundsで開く

このプロジェクトは、iPad上のSwift Playgroundsアプリでも開くことができます。
